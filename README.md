# dsh-stock-portfolio

在 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（DSH）里管理股票持仓：交易记录、盈亏统计、按日线保存的行情、离线代码检索与持仓复盘，全部落在本地 SQLite。

覆盖 A 股（沪深京）、港股、美股，以及 ETF、指数、可转债等标的。侧边栏底部「设置」上方会出现「股票持仓」入口，点开是一个管理面板；界面只用 DSH 自己的主题变量（`--dsw-alias-*`），自动跟随浅色 / 深色主题。

**同一个插件也把交易记录接进了会话**：说一句「昨天买了 100 股腾讯」，缺的字段（价格、日期、动机……）会在同一次调用里弹成一张问题卡片问你，答完即写入面板里的那份数据。见[在 chat 里记交易](#在-chat-里记交易)。

## 功能

| 分区 | 内容 |
| --- | --- |
| **概览** | 持仓市值、总盈亏、浮动盈亏、当日盈亏、已实现盈亏、胜率；按每日收盘价回溯的市值走势图；市场分布与分币种小计 |
| **持仓** | 数量、成本价、最新收盘价（带日期）、当日盈亏、市值、浮动盈亏、已实现盈亏、仓位占比；表头可排序。每行按标的自己的币种显示，组合层面的合计在「概览」里 |
| **交易** | 增 / 改 / 删；表单默认折叠，动机字段旁**按方向给出常用速选词**（买入：低估值买入 / 财报超预期 / 回调加仓…，卖出：止盈 / 止损 / 估值过高…），点一下即填入，也可以自由输入 |
| **分析** | 已实现盈亏记在**卖出**动机上、浮动盈亏按买入动机的成本占比分摊，另有交易所分布、标的表现排行、清仓历史（含持有天数） |
| **设置** | 可选 API Key、基准货币、自动获取的汇率、后台行情检查间隔、本地代码索引与批量请求状态 |

## 在 chat 里记交易

面板之外，同一个插件还向会话注册两个模型可见的 Tool，读写的是同一个 SQLite：

| Tool | 用途 |
| --- | --- |
| `stock_add_trade` | 把一句话变成一笔交易记录 |
| `stock_portfolio_overview` | 读持仓、市值、浮动 / 已实现盈亏与分币种小计 |

说「昨天买了 100 股腾讯」就够了。**用户没说的字段不会被猜**：缺什么，就在同一次调用里通过 `ctx.userQuestions`（内置 `ask_user_question` 用的同一个服务）弹一张问题卡片问什么，而且只弹一张：

| 字段 | 问题的选项来自 |
| --- | --- |
| 标的 | 本地代码索引的命中项（`00700.HK  腾讯控股`）；没有命中就自由输入 |
| 方向 | 买入 / 卖出 |
| 数量 | 自由输入 |
| 价格 | 第一条是本地保存的最新收盘价，并注明「不是你的实际成交价」 |
| 成交日期 | 今天 / 昨天 |
| 动机 | 表单里那组按方向分的速选词、你已经用过的动机，再加一个「不记录动机」 |

用户已经说了的字段不会被再问一遍，所以说全了就一张卡片都不弹。写入走的是 `PortfolioService.addTrade`，和面板保存是同一条校验路径——卖超持仓、数量为 0、日期不合法都会以一句可读的结论返回，而不是写进去。连续录入多笔时，可以让模型传 `ask_motive: false` 跳过动机提问。

**问不出来的时候**：子代理（`DELEGATED_CALLER`）没有人类回答者，组合里也可能根本没挂 `ctx.userQuestions`。这两种情况工具不写入任何东西，而是把还缺的字段和原本要问的问题（含选项）原样返回，模型可以用自己的 `ask_user_question` 接着问。

代码按形状推断出来的符号（例如 `002594` → `002594.SZ`）会写进返回结果的 `notes` 里，模型据此告诉你它推断成了什么。两个 Tool 都挂在插件行上，随插件一起卸载：停用插件行或 `dsh plugin remove` 之后，会话里就不再出现它们。

## 行情与口径

- **只按日线保存。** 每个标的每个交易日一行，没有分时、没有快照表。持仓按最新一个交易日的收盘价估值，「当日盈亏」是与前一交易日收盘价之差，界面上的价格永远带日期。
- **不重复问已经拿到的数据。** 日线在收盘后一天才发布，所以「手里最新的那根已经是数据源能给的最新交易日」的股票，打开面板时**不会产生任何请求**——是否请求由库存数据本身决定，不由定时器决定。确实落后的股票只补 `start_time` = 上次更新次日 → 今天这一段，不重拉整年；几只股票合成一次批量请求；面板打开时顺手检查一次，后台按其间隔再检查，两边同时到达时共用同一次请求。
- **同一天只问一次。** 数据源偶尔会滞后（假期、临时停更），那种情况下股票仍然「落后」，于是记一个「今天已经问过」的水印：一天之内不再重复问，第二天再问。所以一次假期最多花一次请求，而不是每次打开面板都花。
- **新标的当场取最近 90 天。** 一笔交易带来一个从没持有过的代码时——面板里手填的、chat 里说的都一样——写入的同时就按这个窗口拉一次日线，所以保存返回时它已经有价格、市值和当日盈亏，走势图也不用等下一次刷新（90 天约 60 个交易日，刚好越过画曲线所需的下限）。写入最多为这次请求等 2.5 秒，超时先返回、行情在后台继续落地；已经有日线的标的不会重复请求。
- **成本与盈亏不含手续费。** 移动加权平均成本：买入 `cost += 数量 × 价格`，卖出按摊薄成本结转并锁定已实现盈亏。核对券商的费用明细是另一件事，这里记的是「持仓花了多少、拿回多少」。
- **汇率自动获取，一天一次。** 每天第一次打开面板时通过 DSH 自己的 web 能力取 USD→CNY / USD→HKD（`ctx.web.fetch` 优先，失败退回 `ctx.web.search` 解析）；同一天内再打开不会再请求，想立刻更新点设置页的「获取最新」。基准货币默认**人民币 CNY**，汇率来源、汇率日期与更新时间在设置页可见，也可以手动覆盖。
- **代码检索在本地。** 每个交易所的全部标的（约 23,500 条）抓进本地 SQLite，每周更新一次，因此搜索立即返回、可离线、不消耗接口配额。代码写法：`600000.SH` / `00700.HK`（港股补足五位）/ `AAPL.US`；裸代码按形状推断交易所，并把推断结果显示出来。
- **行情数据源可配置。** 不填 Key 也能用（免费端点提供日线），填入 Key 会切到完整服务端点、获得更宽松的限流。Key 的四个来源按优先级为：管理后台设置 &gt; 环境变量 &gt; 项目目录 `.env` &gt; 插件行配置；设置页只回传「已配置 / 未配置」，从不回传密钥本身。

## 安装

插件是标准的 DSH **bundle** + **dual-face client**，两种装法：

```sh
npm install && npm run build

# 方式一（推荐）：装进 profile
dsh plugin --profile web add ~/codespaces/dsh-stock-portfolio
```

```yaml
# 方式二：profile 的 patch 层直接挂载本地 checkout。name 写相对路径即可，
# DSH 会以 patch 文件所在目录为基准解析，配置里不需要绝对路径。
# ~/.dsh/profiles/web/cordis.patch.yml
- insert:
    - id: stock-portfolio
      name: ../../../codespaces/dsh-stock-portfolio/lib/index.js
```

web profile 是 `patchReload: live`，保存后 Host 半边会重组；**浏览器需要刷新一次页面**（`window.__DSH_BOOT__` 在首页渲染时注入，HMR 只换行内容、不新增行）。

改完代码不用重启 `dsh`：

```sh
npm run build     # 额外写一份内容寻址的 lib/index.dev.<digest>.js
npm run reload    # 找到 profile → 把行指向最新的 dev 副本 → touch patch 触发重载
```

可选配置写在 profile 的 patch 行里：`dataDir`（默认 `$DSH_HOME/storages/stock-portfolio`）、`apiBase`、`apiKey`。

## 开发

```sh
npm run build      # lib/index.js（Host）+ lib/client.js（浏览器）+ 类型
npm run watch      # 监听 src/ 重建
npm run typecheck  # tsc --noEmit
npm test           # node --test，全部离线（行情、汇率、提问卡片都有 stub）
npm run reload     # 让运行中的 dsh 换用刚构建的 Host 半边
```

`npm run reload` 改的是 profile 里的 patch 行，而 patch 文件是 `dsh` 每次启动都要解析的文件。所以它按「写同目录临时文件 → rename 覆盖 → 回读校验」替换内容，并先确认要指向的 bundle 存在且非空：一次断电或崩溃不会再留下半截 YAML，把 `dsh` 卡在启动阶段（这个坑真踩过一次）。

数据目录、`.env` 位置、dev 副本路径都在运行时按 `$DSH_HOME` / `import.meta.url` 推导；设置页显示的数据库路径会把 home 目录折叠成 `~`。仓库里没有任何硬编码的绝对路径。

## 已知边界

- 会话里只能**新增**交易和读持仓：改一笔、删一笔仍然在面板里做，因为那两件事需要看见整张表才能判断。
- 指数类裸代码有歧义（`000300` 既是沪深 300 的形状、也是深市股票的形状），需要写后缀或用搜索。
- 批量日线权限因套餐而异；没有权限时刷新会自动改为逐个代码请求，代码多时更慢。
- 不做汇率的历史回溯：市值走势图用**当前**汇率折算。
- 行情按交易日更新，美股与港股收盘时点不同，面板顶部会显示行情的最新日期。
